# JavaScript To-Do List App

## Project Description
A simple To-Do List application developed using JavaScript. It allows users to manage their daily tasks through basic commands using browser prompts.

## Features
- Add new tasks.
- Display all tasks.
- Delete existing tasks.
- Quit the application.

## Technologies Used
- HTML
- JavaScript

## How to Run
1. Open the project website.
2. Enter a command when prompted.
3. Use `add` to add a new task.
4. Use `list` to display all tasks.
5. Use `delete` to remove a task.
6. Use `quit` to exit the application.

## Output
**Note:** The application output is displayed in the browser's Developer Console, not directly on the webpage.

To view the output:
1. Open the website.
2. Press `F12` on your keyboard.
3. Select the **Console** tab.
4. Enter commands in the prompts and view the results in the Console.
