Project Description:
A simple To-Do List application developed using HTML and JavaScript. It allows users to manage their daily tasks through simple commands.

Features:
- Add new tasks.
- Display all tasks.
- Delete existing tasks.
- Quit the application.
  
Technologies Used:
- HTML
- JavaScript
  
How to Run:
1. Download or clone this repository.
2. Open index.html in your browser.
3. Follow the instructions displayed by the application.
